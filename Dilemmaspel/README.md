# Dilemmaspel Studiedata

Online spelvorm gebaseerd op het Dilemmaspel Studiedata van het Versnellingsplan.

## 📋 Beschrijving

Deze interactieve webapplicatie brengt het fysieke Dilemmaspel Studiedata van het Versnellingsplan naar een digitale omgeving. Het spel helpt teams nadenken over ethische vraagstukken rondom studiedata en leeranalytics in het hoger onderwijs.

## 🎯 Doel

Het Dilemmaspel helpt bij:
- Het verkennen van ethische dilemma's rondom studiedata
- Het stimuleren van discussie over privacy en leeranalytics
- Het bewustworden van verschillende perspectieven op data-gebruik
- Het formuleren van beleid rond studiedata

## 🚀 Gebruik

Het bestand `index.html` kan direct in een browser worden geopend. Het spel kan individueel of in groepsverband gespeeld worden.

## 🛠️ Technische Details

- **Type**: Single-page HTML applicatie
- **Technologie**: HTML, CSS (embedded), JavaScript (embedded)
- **Bronmateriaal**: PDF met spelkaarten van het Versnellingsplan
- **Dependencies**: Geen
- **Hosting**: Kan lokaal draaien of op elke webserver

## 📖 Over het Dilemmaspel

Het oorspronkelijke Dilemmaspel Studiedata is ontwikkeld door het Versnellingsplan onderwijsinnovatie met ICT. Deze digitale versie is volledig gegenereerd op basis van de PDF met spelkaarten.

## 📁 Bestanden

- `index.html` - Hoofdapplicatie met het spel
- `sources/` - Bronmaterialen en prompts
