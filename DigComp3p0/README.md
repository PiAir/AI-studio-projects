# DigComp 3.0

Interactieve weergave van het DigComp 3.0 raamwerk voor digitale competenties.

## 📋 Beschrijving

Een webapplicatie die het European Digital Competence Framework (DigComp 3.0) op een toegankelijke manier presenteert. DigComp is een Europees raamwerk dat de competenties beschrijft die burgers nodig hebben om actief deel te nemen aan de digitale samenleving.

## 🎯 Doel

Het raamwerk helpt bij:
- Het identificeren van digitale competenties
- Het opzetten van curricula voor digitale geletterdheid
- Het meten van digitale vaardigheden
- Het creëren van leerdoelen voor digitaal onderwijs

## 🚀 Gebruik

Het bestand `index.html` kan direct in een browser worden geopend of op een webserver worden gehost.

## 🛠️ Technische Details

- **Type**: Single-page HTML applicatie
- **Technologie**: HTML, CSS, JavaScript, JSON
- **Dependencies**: Geen
- **Hosting**: Kan lokaal draaien of op elke webserver

## 📁 Bestanden

- `index.html` - Hoofdbestand met de applicatie
- `digcomp.json` - Structuur en inhoud van het DigComp raamwerk

## 📖 Over DigComp

DigComp 3.0 is ontwikkeld door het Joint Research Centre van de Europese Commissie en beschrijft competenties in vijf gebieden:
1. Information and data literacy
2. Communication and collaboration
3. Digital content creation
4. Safety
5. Problem solving
