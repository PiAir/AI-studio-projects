# Showcase: Geavanceerde Digitale Leermiddelen in Tsjechische Scholen (MŠMT)

Een interactieve webapplicatie die een Tsjechische YouTube-video toegankelijk maakt met meertalige ondertiteling en slimme navigatie.

## 📋 Beschrijving

Deze single-page applicatie integreert een YouTube-video met:
- Meertalige ondertiteling (Nederlands en Engels)
- Overlay-ondertitels die synchroon lopen met de video
- Interactieve navigatiestructuur met topics, vragen en antwoorden
- Tijdcode-gebaseerde navigatie die direct naar relevante delen van de video springt
- Responsive design voor mobiele apparaten en desktop

## 🎯 Doel

Toegankelijk maken van Tsjechische onderwijscontent voor een Nederlands/Engels publiek, met gestructureerde toegang tot de belangrijkste onderwerpen uit de video.

## 🚀 Gebruik

Het bestand `index.html` kan direct in een browser worden geopend. Kies de gewenste taal en klik op topics om door de video te navigeren.

## 🛠️ Technische Details

- **Type**: Single-page HTML applicatie
- **Technologie**: HTML, CSS, JavaScript, VTT (WebVTT ondertiteling)
- **Features**: YouTube API integratie, dual-language support
- **Dependencies**: Geen externe libraries
- **Hosting**: Kan lokaal draaien of op elke webserver

## 📁 Bestanden

- `index.html` - Hoofdapplicatie
- `subtitles_nl.vtt` - Nederlandse ondertitels
- `subtitles_en.vtt` - Engelse ondertitels
- `nl.json` - Nederlandse vertalingen
- `en.json` - Engelse vertalingen

## 📝 Gegenereerd met

AI Studio (Google) - De volledige applicatie, inclusief VTT-bestanden, video-analyse en Q&A structuur, is gegenereerd op basis van één prompt.
