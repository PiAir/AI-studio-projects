# AI Studio Projects

Deze repository bevat een verzameling experimentele webtoepassingen en tools die zijn gegenereerd met behulp van Google AI Studio. De meeste applicaties zijn als standalone HTML-bestanden gebouwd, vaak met embedded CSS en JavaScript, waardoor ze eenvoudig te delen en te hosten zijn.

## 🎯 Doel

Het demonstreren van de mogelijkheden van AI-ondersteunde ontwikkeling, met focus op:
- Snelle prototyping van educatieve tools
- Single-file webapplicaties voor maximale portabiliteit
- Toegankelijke en gebruiksvriendelijke interfaces
- Innovatieve toepassingen voor het onderwijs

## 📱 Applicaties

### Educatieve Tools

#### [Cszech_school_i8n](Cszech_school_i8n/)
Showcase van geavanceerde digitale leermiddelen in Tsjechische scholen. Geïntegreerde YouTube video met meertalige ondertitelingen (Nederlands/Engels) en interactieve navigatiestructuur voor vragen en antwoorden.
- 🔗 [Live demo](https://ictoblog.com/html/Cszech_school_i8n/)
- 📝 [Blogpost](https://ictoblog.nl/2025/05/18/voorbeelden-van-gebruik-digitale-hulpmiddelen-op-een-tsjechische-basisschool)

#### [iXscanv2](iXscanv2/) & [xScan](xScan/)
HTML-versie van de iXscan tool voor zelfevaluatie van digitale geletterdheid. Volledig functionele multi-page applicatie in één HTML-bestand met navigatie, rapportgeneratie en Markdown export.
- 🔗 [Live demo](https://ictoblog.com/html/iXscan/)

#### [TPACK-spel](TPACK-spel/)
Update van de klassieker uit 2014. Interactief spel voor het ontwikkelen van TPACK-competenties door het combineren van Technologie, Pedagogiek en Content Knowledge.
- 🔗 [Live demo](https://ictoblog.com/html/TPACK-spel/)
- 📝 [Blogpost](https://ictoblog.nl/2014/01/25/tpack-the-game)

#### [Weefgetouw](Weefgetouw/)
Digitale versie van het Weefgetouw voor Digitale Geletterdheid. Interactieve tool voor het in kaart brengen van leerdoelen met externe JSON voor flexibele content.
- 🔗 [Live demo](https://ictoblog.com/html/Weefgetouw/)
- 📝 [Blogpost](https://ictoblog.nl/2025/07/14/weefgetouw-digitale-geletterdheidgeletterdheid)

#### [Dilemmaspel](Dilemmaspel/)
Online versie van het Dilemmaspel Studiedata van het Versnellingsplan. Volledig gegenereerd op basis van PDF met spelkaarten.
- 🔗 [Live demo](https://ictoblog.com/html/Dilemmaspel/)

#### [Lesobservaties](Lesobservaties/)
Proof of concept voor video-analyse van klasinteractie gebaseerd op het 5 Docentrollen observatieschema.
- 🔗 [Live demo](https://ictoblog.com/html/Lesobservaties/)

#### [NOLAI-Taiwan](NOLAI-Taiwan/)
Video-presentatie over onderwijsinnovatie in Taiwan met meertalige ondertiteling.

## 🛠️ Technologie

De meeste applicaties zijn gebouwd als:
- **Single-page HTML applicaties** met embedded CSS en JavaScript
- **JSON-configuratie** voor flexibele content
- **Responsive design** voor mobiel en desktop
- **Geen externe dependencies** waar mogelijk

Uitzonderingen:
- **c2pa-viewer**: Vereist Docker (Python/Flask backend)
- **Weefgetouw**: Vereist webserver voor JSON loading

## 🚀 Gebruik

De meeste HTML-bestanden kunnen direct in een browser worden geopend of op een webserver worden gehost. Voor specifieke instructies, zie de README in elke submap.
