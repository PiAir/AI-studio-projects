# Handreiking Onderwijsinnovatie met ICT

Een interactieve handreiking voor onderwijsinnovatie met ICT, gebaseerd op SCORM-content.

## 📋 Beschrijving

Deze applicatie bevat een handreiking die docenten en onderwijsinstellingen helpt bij het innoveren van hun onderwijs met ICT. De content is gebaseerd op bestaand SCORM-materiaal en omgezet naar een webgebaseerde presentatie.

## 🎯 Doel

De handreiking biedt:
- Praktische handvatten voor onderwijsinnovatie
- Inzichten in effectief ICT-gebruik in het onderwijs
- Concrete voorbeelden en richtlijnen
- Structuur voor het implementeren van innovaties

## 🚀 Gebruik

Het bestand `Handreiking Onderwijsinnovatie met ict.html` kan direct in een browser worden geopend.

## 🛠️ Technische Details

- **Type**: HTML applicatie
- **Technologie**: HTML, CSS (mogelijk externe bestanden)
- **Bronmateriaal**: SCORM-pakket (XML metadata bestanden aanwezig)
- **Hosting**: Kan lokaal draaien of op elke webserver

## 📁 Bestanden

### Hoofdbestand
- `Handreiking Onderwijsinnovatie met ict.html` - De hoofdpresentatie

### Bronmaterialen (Sources/)
- `imsmanifest.xml` - SCORM manifest
- Diverse `.xsd` bestanden - XML schema definities voor SCORM
- Backup versies van code

### Afbeeldingen (images/)
- Ondersteunende afbeeldingen voor de handreiking

## 📖 Over SCORM

SCORM (Sharable Content Object Reference Model) is een standaard voor e-learning content. De oorspronkelijke content is getransformeerd naar een standalone webapplicatie.
