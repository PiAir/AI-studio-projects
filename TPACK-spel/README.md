# TPACK-spel

Een interactieve tool voor het ontwikkelen van TPACK-competenties (Technological Pedagogical Content Knowledge) bij docenten.

## 📋 Beschrijving

Een update van een klassieker uit 2014, maar nu volledig zelfstandig zonder externe CSS en JavaScript. Het spel gebruikt JSON voor de onderdelen en helpt docenten bij het bedenken van werkvormen die technologie, pedagogiek en vakinhoud combineren.

## 🎯 Doel

Het idee is dat je de 3 componenten shuffelt (Technologie, Pedagogiek, Content) en dan een werkvorm bedenkt die alle drie de aspecten integreert. Dit stimuleert creatief denken over hoe technologie effectief ingezet kan worden in het onderwijs.

## 🚀 Gebruik

Het bestand `index.html` kan direct in een browser worden geopend. De applicatie werkt volledig lokaal zonder externe dependencies.
