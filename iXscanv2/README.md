# iXscan v2

Verbeterde versie van de iXscan tool met Word export en responsive design.

## 📋 Beschrijving

De iXscan v2 is een HTML-versie van de oorspronkelijke Excel-gebaseerde iXscan tool voor zelfevaluatie van digitale geletterdheid. Deze versie is ontwikkeld op basis van een schermfilmpje van de oorspronkelijke Excel-versie en biedt significante verbeteringen.

## 🎯 Doel

De iXscan helpt onderwijsprofessionals bij:
- Het in kaart brengen van hun digitale competenties
- Het identificeren van ontwikkelpunten
- Het maken van een persoonlijk ontwikkelplan
- Het monitoren van groei in digitale vaardigheden

## ✨ Verbeteringen t.o.v. v1

- **📱 Responsive**: Werkt perfect op mobiele telefoons
- **📄 Word export**: Genereer een Word-document met je resultaten
- **🎨 Modern design**: Eigentijdse en gebruiksvriendelijke interface
- **🚀 Betere navigatie**: Verbeterde multi-page ervaring

## 🚀 Gebruik

Open `index.html` in een browser en doorloop de vragenlijst. Na afronding kun je:
- Je resultaten bekijken
- Een rapport exporteren naar Word
- Je voortgang opslaan

## 🛠️ Technische Details

- **Type**: Single-page HTML applicatie (ogenschijnlijk multi-page)
- **Technologie**: HTML, CSS, JavaScript
- **Features**: 
  - Dynamische navigatie tussen secties
  - Rapportgeneratie
  - Word document export (.docx)
  - Lokale opslag van resultaten
- **Dependencies**: Geen externe libraries nodig
- **Hosting**: Kan lokaal draaien of op elke webserver
