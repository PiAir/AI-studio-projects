# Vibecoding - 20+ App Showcase

Een verzameling van 20+ kleine webapplicaties die demonstreren wat een docent in één prompt kan creëren met AI Studio.

## 📋 Beschrijving

Vibecoding is een showcase project met meer dan 20 verschillende kleine applicaties, elk ontstaan uit een enkele prompt aan AI Studio. Het project demonstreert de snelheid en veelzijdigheid waarmee docenten functionele webtoepassingen kunnen creëren, elk compleet met screenshots.

## 🎯 Doel

Het project illustreert:
- De toegankelijkheid van app-ontwikkeling voor niet-programmeurs
- Snelle prototyping van onderwijstools
- Diversiteit aan mogelijke toepassingen
- Kracht van AI-ondersteunde ontwikkeling

## 📱 Applicaties

De repository bevat 21 verschillende app-versies (`app-1.html` t/m `app-21.html`), elk met unieke functionaliteit en design. Een overzichtspagina toont alle beschikbare applicaties.

## ✨ Features

- **21 verschillende apps**: Van eenvoudig tot complex
- **Screenshots**: Visuele voorbeelden van elke app
- **JSON configuratie**: `applications.json` met metadata
- **Overzichtspagina**: `index.html` toont alle apps in een grid

## 🚀 Gebruik

Open `index.html` om het overzicht te zien van alle beschikbare applicaties. Elke individuele app kan ook direct worden geopend via `app-X.html`.

## 🛠️ Technische Details

- **Type**: Collectie van single-page HTML applicaties
- **Technologie**: HTML, CSS (embedded), JavaScript (embedded)
- **Configuratie**: `applications.json` voor metadata
- **Dependencies**: Geen
- **Hosting**: Kan lokaal draaien of op elke webserver

## 📁 Bestanden

- `index.html` - Hoofdoverzicht van alle apps
- `app-1.html` tot `app-21.html` - Individuele applicaties
- `applications.json` - Metadata van alle applicaties
- `index.bak.html` - Backup van het hoofdbestand

## 💡 Inspiratie

Dit project is bedoeld om docenten te inspireren en te laten zien wat mogelijk is met moderne AI-tools. Elke app is een voorbeeld van "vibe coding" - het creëren van software door je intentie te beschrijven in plaats van code te schrijven.

## 📝 Gegenereerd met

AI Studio (Google) - Set van 20+ kleine apps die een docent kan creëren in 1 prompt, inclusief screenshots van de apps.
