# Conjecture Mapping Tool

Een interactieve tool voor het maken van Conjecture Maps voor onderwijskundig ontwerp.

## 📋 Beschrijving

Een eenvoudige maar krachtige HTML-applicatie voor het maken van Conjecture Maps. Conjecture Mapping is een methode voor het in kaart brengen van ontwerphypotheses in onderwijskundig ontwerp, waarbij je verbanden legt tussen ontwerpkeuzes, leeractiviteiten en verwachte uitkomsten.

## 🎯 Doel

De tool helpt onderwijsontwerpers bij:
- Het visualiseren van ontwerpkeuzes en hun onderlinge relaties
- Het expliciteren van verwachtingen over leerprocessen
- Het creëren van overzichtelijke diagrammen voor design-based research
- Het delen en bewaren van ontwerprationales

## ✨ Features

- **Visueel ontwerpen**: Interactieve canvas voor het maken van conjecture maps
- **Export naar SVG**: Bewaar je map als schaalbaar vectorformaat
- **JSON opslag**: Sla je werk lokaal op en laad het later weer
- **Screenshot functie**: Maak PNG-afbeeldingen via de browser
- **Browser-based**: Geen installatie nodig

## 🚀 Gebruik

1. Open `index.html` in een browser
2. Maak je conjecture map door elementen toe te voegen en te verbinden
3. Exporteer naar SVG of sla op als JSON voor later gebruik
4. Voor PNG: open de SVG in de browser en maak een screenshot
