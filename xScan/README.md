# xScan - iXscan SCORM versie

HTML-versie van de iXscan tool voor zelfevaluatie van digitale geletterdheid, met SCORM-metadata.

## 📋 Beschrijving

De xScan is een eerdere versie van de iXscan tool, verpakt met SCORM (Sharable Content Object Reference Model) metadata. Deze versie bevat de zelfevaluatietool in een formaat dat compatibel is met leerplatformen die SCORM ondersteunen.

## 🎯 Doel

De iXscan helpt onderwijsprofessionals bij:
- Het in kaart brengen van hun eigen digitale competenties
- Het identificeren van ontwikkelbehoeften
- Het formuleren van professionaliseringsdoelen
- Het monitoren van groei in digitale geletterdheid

## 🚀 Gebruik

- **Hoofdbestand**: `ixscan.html` - De applicatie zelf
- **SCORM**: `imsmanifest.xml` - Voor integratie in leerplatformen

Open `ixscan.html` direct in een browser of importeer het SCORM-pakket in een LMS.

## 🛠️ Technische Details

- **Type**: SCORM-compatibele webapplicatie
- **Technologie**: HTML, CSS, JavaScript
- **SCORM versie**: 1.2 (op basis van schema's)
- **Dependencies**: Geen voor standalone gebruik
- **Hosting**: Kan lokaal draaien of via LMS
