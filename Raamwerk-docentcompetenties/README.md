# Raamwerk Docentcompetenties

Interactieve weergave van het raamwerk voor docentcompetenties in het Nederlandse onderwijs.

## 📋 Beschrijving

Een webapplicatie die het raamwerk voor docentcompetenties op een overzichtelijke en toegankelijke manier presenteert. Het raamwerk beschrijft welke competenties docenten nodig hebben voor goed onderwijs.

## 🎯 Doel

Het raamwerk helpt bij:
- Het identificeren van ontwikkelbehoeften van docenten
- Het opstellen van professionaliseringsplannen
- Het evalueren van docentcompetenties
- Het structureren van opleidingsprogramma's

## 🚀 Gebruik

Het bestand `index.html` kan direct in een browser worden geopend of op een webserver worden gehost.

## 🛠️ Technische Details

- **Type**: Single-page HTML applicatie
- **Technologie**: HTML, CSS, JavaScript
- **Dependencies**: Geen
- **Hosting**: Kan lokaal draaien of op elke webserver

## 📖 Over het Raamwerk

Het raamwerk voor docentcompetenties beschrijft de bekwaamheidseisen voor docenten en is gebaseerd op de bekwaamheidseisen van de SBL (Stichting Beroepskwaliteit Leraren).
