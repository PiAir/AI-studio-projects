# Analyse Klasinteractie: 5 Docentrollen

Proof of concept voor video-analyse van klasinteractie gebaseerd op het observatieschema van 5 Docentrollen.

## 📋 Beschrijving

Deze experimentele tool analyseert video-opnames van lessen aan de hand van het 5 Docentrollen observatieschema en genereert automatisch een rapportage. Het is een proof of concept ontwikkeld met video-opnames van de HAN.

## 🎯 Doel

De tool demonstreert hoe AI kan helpen bij:
- Het analyseren van lesgedrag volgens het 5 Docentrollen model
- Het automatisch genereren van observatierapporten
- Het geven van feedback op docentgedrag
- Het ondersteunen van professionalisering van docenten

## 📊 5 Docentrollen Model

Het observatieschema is gebaseerd op het model van 5 Docentrollen dat verschillende aspecten van docentgedrag in kaart brengt tijdens een les.

## 🚀 Gebruik

De verschillende HTML-bestanden bevatten verschillende varianten van de analyse:
- `Lesobservatie-5-docentrollen-video3-variant1.html`
- `Lesobservatie-5-docentrollen-video4-variant2.html`
- `Lesobservatie-5-docentrollen-video4.html`
- `Lesobservatie-video1-variant2.html`
- `Lesobservatie-video1.html`
- `Lesobservatie-video2.html`
