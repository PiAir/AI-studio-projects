# Video Embed Creator

Tool voor het genereren van embed code voor video's, met ondersteuning voor custom video URLs.

## 📋 Beschrijving

Deze tool genereert embed code voor video's en kan, indien voorzien van een URL-encoded video URL, direct een player tonen met de video. Hoewel technisch niet gemaakt met AI Studio maar met Gemini, past het goed in de collectie van educatieve tools.

## 🎯 Doel

De tool is handig voor:
- Het embedden van video's in webpagina's
- Het werken met custom video hosting (zoals Jellyfin)
- Het tonen van video's zonder externe afhankelijkheden
- Integratie met persoonlijke media servers

## 💡 Use Case

Voorbeeld gebruik: het embedden van video's van recepten gehost op Jellyfin in een Mealie installatie (recepten beheer systeem).

## 🚀 Gebruik

Het bestand `index.html` kan direct in een browser worden geopend. Voer een video URL in om de embed code te genereren of de video direct af te spelen.
